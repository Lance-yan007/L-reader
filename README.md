# L-reader

智能英文阅读器 - 支持 PDF 阅读、划词翻译、生词本和 AI 助手

## 功能特性

- 📖 PDF 阅读和标注
- 🔤 划词翻译
- 📚 生词本管理
- 🤖 AI 阅读助手
- ☁️ 云端数据同步

## 本地开发

```bash
# 启动本地服务器
python3 -m http.server 8081

# 访问
http://localhost:8081/app.html
```

## 技术栈

- 前端：原生 JavaScript + HTML + CSS
- PDF 渲染：PDF.js
- 后端服务：Supabase
- 部署：Vercel
